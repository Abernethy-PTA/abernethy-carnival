# Abernethy Carnival

Static site for the Abernethy Elementary School Carnival — Friday, May 15, 2026, 5:30–8:00 PM.

**Live:** http://carnival.supportabernethy.org

## Stack
Plain HTML/CSS. No build step. Fonts from Google Fonts (Passion One, Abril Fatface, Lora). Section art is AI-generated poster imagery on a cream background with ornate vintage-circus frames.

## Files
- `index.html` — the site
- `*.png` — poster/section images and screenshot artifacts
- `inflatables/`, `inflatables-web/` — 2026 inflatable assets
- `CLAUDE.md` — project notes for Claude Code

## Deploy
Hosted on GitHub Pages from the `main` branch of `Abernethy-PTA/abernethy-carnival` (root `/`). Push to `main` to deploy. The deploy-ready copy with compressed JPGs lives in `/tmp/carnival-deploy/`.

## DNS
`carnival` CNAME → `abernethy-pta.github.io` in Squarespace Domains for `supportabernethy.org`.
